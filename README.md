# Shivani Gupta | Data Engineer & Analyst Portfolio

A personal portfolio showcasing my experience in data engineering, analytics, and business intelligence. Built using **React, TypeScript, Tailwind CSS, and Framer Motion**, the website highlights my technical skills, projects, certifications, and academic achievements through an interactive and modern design.

---

## ⚡ Running Locally

The development server is configured to run at:

**http://localhost:3000/**

---

## 🚀 Portfolio Features

### 1. Interactive Design and Data Visualizations

- **Light and Dark Themes:** Switch between light and dark modes based on your preference.
- **Animated Data Background:** A canvas-based network animation inspired by data pipelines and interconnected systems.
- **Medallion Architecture:** Explore the Bronze, Silver, and Gold layers, including raw data ingestion, data cleansing, historical tracking using SCD Type 2/3, and curated data models.
- **Interactive Terminal:** A command-line-style interface where visitors can explore different sections using commands such as `help`, `about`, `education`, `fabric --status`, `stats`, `certifications`, `projects`, and `contact`.

### 2. Professional Profile and Academic Achievements

The portfolio includes my professional profile, technical experience, certifications, and academic accomplishments.

- **MCA Bronze Medalist** — National Institute of Technology (NIT), Raipur.
- **Chancellor's Medal Holder (BCA)** — Bundelkhand University, University Rank 1.

The profile section also features animated visual elements highlighting selected milestones, including experience with large-scale datasets, certifications, and products in General Availability (GA).

### 3. Contact and Professional Links

The contact section is designed to make it easy to connect while reducing exposure to automated spam.

- Email and phone details are kept out of the page's visible text.
- An interactive verification challenge helps discourage automated submissions.
- Direct links provide access to my LinkedIn and GitHub profiles.

## 🛠️ Getting Started

### Prerequisites

Make sure Node.js and npm are installed on your system.

### Start the Development Server

```bash
npm install
npm run dev
```

Open **http://localhost:3000/** in your browser.

### Build for Production

```bash
npm run build
```

The optimized production files are generated in the `dist/` directory.

### Preview the Production Build

```bash
npm run preview
```
